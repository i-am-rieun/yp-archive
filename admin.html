운영 및 백업

데이터 백업 및 변경 이력을 확인합니다.

데이터 백업

현재 관리자 세션으로 조회 가능한 핵심 콘텐츠 테이블을 JSON 파일로 내보냅니다.

백업 파일에는 프로그램, 시즌, 출연자(어록 포함), 커플, 뉴스 링크, 명언이 포함됩니다. 이미지 원본, Auth 사용자 정보, 사이트 공통 설정, 변경 이력은 포함되지 않습니다.

데이터 변경 이력

주요 콘텐츠 테이블의 등록·수정·삭제를 기록합니다. 과거 변경 내역은 소급되지 않습니다.

백업 범위

JSON 내보내기는 현재 관리자 화면에서 조회한 핵심 데이터 기준입니다. 이미지 원본, Auth 계정, 사이트 공통 설정 및 변경 이력은 별도 관리 대상이며 이 JSON 파일로 자동 복원되지 않습니다.
